# 试卷维度页码安全擦除设计

## 1. 目标

新建独立 skill：`/Users/longxuebin/.claude/skills/xb-to-sgc-by-paper-erase`。

它按“学科/试卷 ID/学校ID_试卷ID_图片顺序”聚合同一份试卷，通过视觉模型先分析全卷页码共性，再逐页定位；Java 负责确定性旋转、风险分流、墨迹掩码擦除、像素门禁、回退、Word 合并和报告。

验收优先级：

1. 正文有效墨迹不得被擦除，误擦零容忍。
2. 页码及与页码同行、可确认属于非正文的元数据擦除准确率不低于 99%。
3. 擦除区域与邻近纸张背景基本无可见色差。
4. 无法同时满足安全与去除目标时保留原图并进入 `manual_review`。

## 2. 范围

第一版只处理页码，以及与页码处于同一独立页眉/页脚元数据带、语义明确不属于正文的学校名、试卷名、出版社、标语等内容。不处理无页码锚点的独立水印、密封线、普通页眉或其他装饰。

支持：

- 单页、旋转页和一图双页；
- 同卷奇偶页左右交替、答案页位于页眉、末页版式变化等多个合法模式组；
- 每卷最多 8 张图片一个共性分析批次，批次重叠 1 张；
- 同一模型的不同角色提示词，且各角色模型均可独立配置；
- 原图 Word、擦除后 Word、逐页证据、全卷共性和测试报告。

不包含：

- 生产 REST 接口、数据库回写或远程推送；
- 修改、删除或运行时引用旧 `xb-to-sgc-by-erase`；
- 自动裁白边；
- 无人工金标情况下宣称已经达到 99%。

## 3. 输入契约

测试集结构：

```text
<测试根>/<学科>/<试卷ID>/<学校ID>_<试卷ID>_<图片顺序>.<png|jpg|jpeg|webp>
```

规则：

- 目录名是权威 `exam_id`；文件名最后一个下划线后的正整数是 `page_order`。
- 文件中间的试卷 ID 与目录名不一致时记录异常，以目录名为准。
- 无法解析页序或页序重复时整卷拒绝处理。
- 页序缺号时允许继续，但写 `page_sequence_incomplete=true`，并使相关页面进入风险判定。
- 模型请求和响应使用稳定 `page_id`，禁止只靠数组下标对齐。

门禁集选择：从 `所有学科100份试卷_bad图` 提取 74 张失败图涉及的试卷 ID，再按试卷 ID 到同级 `所有学科100份试卷` 全局查找完整试卷。不能依赖 bad 目录中的学科名，因为已发现试卷 `2316009299909402922` 在 bad 目录被误放到“数学”，完整集实际位于“语文”。

## 4. 视觉流水线

### 4.1 全卷共性分析

将页面转换为长边不超过 1536 的预览图。每批最多 8 张，相邻批次重叠一张，例如 `1-8、8-15、15-18`。

共性模型只输出：

- 每页阅读方向 `0|90|180|270` 及置信度；
- 一个或多个 `pattern_groups`；
- 每组页码所在边缘、对齐方式、版式描述、成员 `page_ids` 和置信度；
- 异构页、疑似无页码页和无法归组页。

共性不得产生最终擦除坐标，也不得把一页坐标复制给另一页。跨批次结论冲突时保留多个模式或降级为 `mixed`。

### 4.2 Java 方向标准化

VLM 只判断方向，Java 负责旋转像素：

- 方向置信不足时页面直接 `manual_review`；
- 90°/270°允许宽高互换；
- 不缩放、不裁切、不补白；
- 后续定位、擦除和审核均在正常阅读方向的工作图上进行；
- JSON 保存原始尺寸、最终尺寸、方向和坐标变换。

### 4.3 单页候选定位

每页独立发送正常方向全页预览，并携带该页所属模式组的文本证据。模型返回：

- `safe_to_erase|no_pagenum|manual_review`；
- 一个或多个独立 `region_id`；
- 0 到 1 的有限坐标；
- 页码文本、同行元数据语义、是否在线上、置信度和安全边界；
- 最近正文边界和推理证据。

只有存在明确页码锚点时才允许扩展至同行元数据。左右文字语义不明确时降级为只擦页码本体。

### 4.4 风险触发局部复核

仅当下列条件全部满足时允许跳过擦前局部复核：

- 定位置信度达到经数据集校准的阈值，初始值 0.97；
- 与稳定模式组一致；
- 坐标位于相应页面边缘带；
- Java 像素分析确认目标与正文间存在完整空白分隔；
- 墨迹掩码不触碰候选框边界；
- 不是旋转、双页、首尾异构页；
- 全卷结论不是 `mixed/uncertain`；
- VLM 正文边界与 Java 检测不冲突。

任一条件失败时，二检同时输入：

1. 长边不超过 1536 的全页预览；
2. 从原始分辨率工作图裁出的高清 ROI，包含候选区域、上下留白和最近正文行。

候选为空但与同卷共性冲突时，根据模式组从对应页边缘生成 ROI。二检仍不安全则 `manual_review`。

## 5. Java 安全擦除

### 5.1 硬校验

每个 region 必须通过：

- 页 ID、region ID 唯一；
- 坐标有限且满足 `0 <= x1 < x2 <= 1`、`0 <= y1 < y2 <= 1`；
- 面积和边缘位置合理；
- 坐标映射未越界；
- 正文安全间隔通过；
- 目标墨迹掩码不触碰框边界。

禁止将模型 `confidence` 或文字 `reasoning` 当作单独放行依据。

### 5.2 墨迹掩码

VLM 坐标只限定候选范围。Java 在框内估算局部背景并提取深于背景的文字墨迹及抗锯齿边缘，只修改批准掩码内的像素：

- 禁止在模型框外扩张；
- 禁止旧实现的框外残点扫描；
- 掩码接触边界时重新送检或人工复核；
- 背景平稳时用稳健局部背景修复；
- 轻微渐变时拟合局部颜色平面；
- 纹理、印章、复杂横线或背景方差过大时不擦。

页码压在直线上时，仅当两侧线段方向、颜色和粗细一致，才能在字符移除后插值恢复直线；无法证明不是正文表格线时进入人工复核。

### 5.3 擦后确定性门禁

- 正常方向输出图尺寸不得发生非旋转导致的变化；
- 批准掩码之外的像素必须与旋转后的原图逐像素一致；
- 修复区域边界色差和局部方差必须通过阈值；
- 任一失败立即丢弃擦后结果并回退原图。

### 5.4 擦后 VLM 门禁

每个实际发生修改的页面都要审核，不能抽样。审核使用独立提示词，输入原图/擦后图的全页预览及目标 ROI。若发现正文变化、目标残留、色差明显或无法确认，页面回退原图并标记 `manual_review`。

## 6. 状态与失败隔离

页面状态：

- `safe_to_erase`：所有门禁通过，正式使用擦后图；
- `no_pagenum`：无页码，原图透传；
- `needs_recheck`：内部中间状态，不直接发布；
- `manual_review`：保留原图，生成审核预览；
- `error`：模型、解析或工程异常，按人工复核处理。

单页风险只阻断该页。输入页序重复、模型响应页映射错乱或共性协议无法解析时整卷回退。不同试卷之间完全隔离。

## 7. 输出结构

```text
<测试根>/xb-to-sgc-by-paper-erase-output/
└── exam-page-only/
    └── runs/<模型>@<时间戳>/
        ├── erased/<学科>/<试卷ID>/
        │   ├── <页面>_原图.png
        │   ├── <页面>_擦除后.png
        │   ├── <页面>_人工审核预览.png
        │   └── <页面>_regions.json
        ├── consensus/<学科>/<试卷ID>/exam_consensus.json
        ├── word_output/<学科>/<试卷ID>/
        │   ├── <试卷ID>_原图.docx
        │   └── <试卷ID>_擦除后.docx
        ├── _audit.ndjson
        ├── 测试报告/测试报告.md
        └── run.json
```

`_原图.png` 永不加水印。`_擦除后.png` 在回退时是原图副本，也不加水印。`_人工审核预览.png` 才添加半透明红色“需人工审核”；擦除后 Word 对人工页使用该预览，原图 Word 始终使用无水印原图。

Word 合并类和模板从旧 skill 复制后独立维护，运行时不得引用旧 skill。

## 8. 配置

默认 VLM 为 `qwen3.8-max`。配置至少分为：

- `pattern`：全卷共性；
- `locate`：单页定位；
- `verify`：局部安全复核；
- `audit`：擦后审核。

四个角色默认可以指向同一个 qwen 模型，但 prompt 必须独立，且 endpoint/model/api-key env 可分别覆盖。网络失败按角色配置重试，最终失败不得擦除。

## 9. 验收

### 9.1 自动测试

- 文件名解析、自然页序、重复/缺号；
- 8 页分批及 1 页重叠；
- 多模式组与跨批冲突；
- 方向旋转、宽高互换和像素完整性；
- 坐标、风险门禁和 ROI 映射；
- 掩码不得越框、复杂背景拒绝、直线恢复；
- 掩码外逐像素不变和失败回退；
- 人工水印不污染正式 PNG；
- 两份 Word 页数与顺序一致。

### 9.2 第一阶段门禁

只运行 74 张 baseline bad 图涉及的完整试卷，默认 VLM `qwen3.8-max`。产物生成后停下让用户查看，不继续跑完整 100 份/400 页。

### 9.3 最终生产门禁（本轮不执行）

使用完整 100 份/400 页人工金标集：正文保护区有效墨迹变化为 0，目标擦除准确率不低于 99%，非目标误擦页数为 0；`manual_review` 独立统计，不伪装成功。
